# 🚀 Rock Paper Scissors Game ✊✋🖖

## Overview
The **Rock Paper Scissors Game** is a simple and fun game where the player competes against the computer. The player can choose between **Rock**, **Paper**, or **Scissors**, and the computer randomly selects one as well. The game then determines the winner based on the rules:
- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock

---

## Key Features:
- **Simple Gameplay**: The player can select **Rock**, **Paper**, or **Scissors** by clicking buttons.
- **Random Computer Selection**: The computer randomly picks one of the three options.
- **Winning Logic**: The game calculates the winner based on the standard **Rock Paper Scissors** rules.
- **Score Tracking**: Displays the current score for both the player and the computer.
- **User Feedback**: Displays messages about the outcome (win, lose, or tie).
- **Responsive Interface**: A simple and responsive UI for easy gameplay.
